# stylestore-data-analysis

Analisi dati e-commerce moda: validazione Excel per la validazione, SQL per la scalabilità, Power BI per la comunicazione.

## Cosa contiene questo repository

Il file 'StyleStore_Queries.sql' raccoglie le query SQL del progetto, organizzate in sezioni:
- Setup e verifica import
- Validazione e integrità dei dati
- Analisi per categoria
- Analisi temporale e window functions
- Query avanzate (subquery, CTE)

Ogni query è commentata con il suo scopo e il risultato atteso.
